Pickets setup is intentionally small and transparent.
The setup wrapper is built with the open-source Inno Setup project.

WHAT SETUP CHANGES

* Copies one self-contained application, Pickets.exe, to the folder you choose.
  The default is your per-user Local AppData\Programs\Pickets folder.
* Adds a Start menu shortcut.
* Adds a desktop shortcut only if you leave that option selected.
  The first-run guide remembers this choice, including when you decline the shortcut.
* Remembers the installation folder and shortcut choice in your Windows user settings.
* Starts Pickets at sign-in only if you explicitly select that option.

WHAT SETUP DOES NOT DO

* It does not require administrator access or install a Windows service or driver.
* It does not connect to the internet, add telemetry, or create an account.
* It does not move, upload, or modify your files.
* It does not change Windows desktop arrangement settings for you.

UNINSTALL AND YOUR DATA

Uninstall first asks Pickets to restore captured desktop icons. If recovery cannot finish, it stops
before removing files and offers Retry or Cancel. After success, it removes the app and installer-
created shortcuts. Your layout remains in %APPDATA%\Pickets so reinstalling can recover it. You can
remove that folder manually if you also want to erase saved layouts and diagnostic logs.
