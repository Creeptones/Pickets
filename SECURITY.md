# Security policy

## Supported version

Security fixes are provided for the latest published version of Pickets.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/Creeptones/Pickets/security/advisories/new)
to share the impact, reproduction steps, and any proof of concept.

Pickets is a local desktop utility. It does not include accounts, a network service, telemetry, or
an update client. Reports involving unsafe file launching, path handling, release integrity, or
unexpected disclosure through diagnostics are still in scope.
